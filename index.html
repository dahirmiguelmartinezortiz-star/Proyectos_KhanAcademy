Transformación de Gráficos: Khan Academy a Entorno Web Nativo

En este sitio se recopilan los retos y proyectos originalmente desarrollados en el entorno educativo de Khan Academy, adaptados para ejecutarse en navegadores web modernos mediante código estándar con la API de HTML5 Canvas y la biblioteca p5.js.

1. El elemento HTML <canvas> y el Contexto de Renderizado 2D

La etiqueta <canvas> define un área de mapa de bits dependiente de resolución. Por sí misma no posee capacidad de dibujo; delega toda la renderización a una interfaz de programación de aplicaciones (API) en JavaScript a través del contexto 2D ('2d'). 

const canvas = document.getElementById('miCanvas');
const ctx = canvas.getContext('2d');

// Ejemplo de trazado nativo
ctx.fillStyle = '#6366f1';
ctx.fillRect(20, 20, 100, 60);

ctx.beginPath();
ctx.arc(200, 50, 30, 0, Math.PI * 2);
ctx.fillStyle = '#10b981';
ctx.fill();

El contexto 2D gestiona primitivas vectoriales mediante trazados manuales (beginPath(), moveTo(), lineTo(), arc()), transformaciones euclidianas y composición de color directa sobre píxeles.

2. Fundamentos de la Librería p5.js

p5.js es una biblioteca de JavaScript orientada a la programación visual interactiva basada en la filosofía de Processing. Abstrae la manipulación de bajo nivel del elemento <canvas> organizando la lógica mediante su ciclo de vida estándar:

  • setup(): Función que se ejecuta una sola vez al cargar la página. Inicializa el tamaño del lienzo (createCanvas()), modos de color y configuraciones estáticas.
  • draw(): Ciclo continuo de renderizado (típicamente a 60 cuadros por segundo) para animaciones e interactividad reactiva a eventos periféricos. Para gráficos fijos se desactiva con noLoop().
